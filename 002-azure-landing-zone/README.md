# Azure Landing Zone

This project impelementes a reusable Azure Landing Zone. It establishes a secure and scalable baseline for Azure environments by defining governance, identity structure, and network segmentation.

## Project Goals

The primary goal of this project is to create a reusable Azure foundation that:
- Establishes governance using Azure Policies
- Separates responsibilities using resource group structure and RBAC
- Implements a hub-and-spoke network architecture with centralized network connectivity and traffic inspection
